# Exploring Linguistic Levels with Python

## 📌 Overview

This mini-project explores different **levels of linguistic analysis** using Python and NLP libraries.

The notebook covers six major linguistic levels:

1. Phonology
2. Morphology
3. Syntax
4. Lexicon
5. Semantics
6. Pragmatics

Each section uses NLP tools and examples to demonstrate how language can be analyzed from sounds and word structure to meaning and context.

## 🎯 Objectives

- Understand the main levels of linguistic analysis.
- Connect linguistic theory with practical NLP techniques.
- Experiment with Python-based linguistic resources.
- Compare how different NLP libraries support different linguistic tasks.

## 🔬 Topics Covered

### Phonology
Explores pronunciation and phonetic representations using resources such as CMU Pronouncing Dictionary.

### Morphology
Examines word structure and relationships between words and their forms.

### Syntax
Explores sentence structure and grammatical relationships.

### Lexicon
Investigates words and lexical relationships.

### Semantics
Uses NLP techniques to explore meaning and semantic similarity.

### Pragmatics
Explores how context can affect interpretation and meaning.

## 🛠️ Technologies

- Python
- NLTK

- Sentence Transformers
- CMU Pronouncing Dictionary
- WordNet
