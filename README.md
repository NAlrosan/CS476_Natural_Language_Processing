# NLP Projects

A collection of mini-projects and experiments covering Natural Language Processing, text preprocessing, language modeling, multilingual embeddings, Arabic NLP, and linguistic analysis.

## 📁 Projects

| Project | Description |
|---|---|
| [Byte Pair Encoding](./Byte_Pair_Encoding/) | BPE tokenizer implemented from scratch |
| [CAMeL Tools](./CAMeL_Tools/) | Arabic morphological analysis, generation, and reinflection |
| [English–Spanish Embeddings](./Eng_Esp_Embedding_Project/) | Cross-lingual Word2Vec and embedding experiments |
| [Linguistic Levels](./Linguistic_Levels/) | Computational exploration of phonology, morphology, syntax, lexicon, semantics, and pragmatics |
| [N-Grams](./N_Grams/) | Trigram language model and next-word prediction |
| [Sentiment Analysis](./SA_Log_Regression/) | IMDB sentiment classification using TF-IDF and Logistic Regression |
| [Text Preprocessing](./Text_preprocessing/) | Practical NLP text-cleaning and normalization techniques |
